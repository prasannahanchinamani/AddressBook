# AddressBook
Address Book Management System
Simple C# console-based Address Book application.

What it does
Create multiple address books
Add, edit, delete contacts
Display contacts
Search contacts by city or state
Count contacts by city and state
Save and load address books using CSV
Save and load address books using SQL Database


Technologies Used
C#
.NET Console Application
Collections (Dictionary, List)
File Handling (CSV)
SQL Server (ADO.NET)
Storage-sql server
CSV file
SQL Server database
